The module is a pure data fixture directory consumed by the evaluation harness. Each golden case lives under `fixtures/golden/<case>/` as a self-contained unit consisting of a `figma.json` (the reference design) and a `config.json` that declares tolerance thresholds (`minSimilarity`) and repair limits (`maxRepairIterations`). The `metrics/` subdirectory exists as a placeholder for evaluation metric definitions or results. There is no executable code in this scope — it is a read-only input layer that the harness loads at test time to drive comparison and repair loops.
