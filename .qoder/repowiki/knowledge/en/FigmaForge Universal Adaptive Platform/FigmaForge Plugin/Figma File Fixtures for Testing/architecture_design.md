Pure data directory under `plugin/figmaforge/fixtures/figma/` containing hand-crafted `.json` files that conform to the Figma REST API contract. Each file represents a self-contained Figma file snapshot (e.g. `file.json`, `variants.json`) or an API payload (`figma_api_response.json`, `images.json`). The fixtures are organized by scenario: layout variants (`layout_desktop.json`, `layout_mobile.json`, `layout_tablet.json`, `layout_nested.json`, `layout_content_overflow.json`) exercise different frame/container configurations, while `variants.json` covers component sets with multiple component variants and bound variables. Consumers load these files as test inputs; there is no executable code in this module — it is consumed only by sibling test suites via static file reads.
