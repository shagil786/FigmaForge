Requires two external JSON manifests to exist at runtime: `plugin/figmaforge/library/components.json` + `tokens.json` (loaded by `LibraryLoader.load()`) and `plugin/figmaforge/catalog/roles.json` (loaded by `Catalog`). Missing files raise explicit errors (`FileNotFoundError` for roles.json, `FigmaResponseError` for missing library manifests). The asset store root is created lazily under the configured `storage_dir` with a two-level hash-prefixed directory layout.
