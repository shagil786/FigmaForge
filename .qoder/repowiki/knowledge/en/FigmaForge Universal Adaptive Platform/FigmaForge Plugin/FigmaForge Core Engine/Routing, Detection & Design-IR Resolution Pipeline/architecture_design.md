The module is organized as a staged pipeline with clear dependency direction: (1) `detector.RepositoryDetector` scans the filesystem for languages, frameworks, package managers, CI/IaC, MCP/LSP configs and computes a confidence score that classifies the repo as `classified` or `unclassified`; (2) `router.Router` consumes the detector output plus a `Catalog` of roles to score each role by trigger keywords, lifecycle-phase overlap, domain relevance, deliverable matches, installed capability refs, and stack-status penalties, returning a `RouteResult` that selects top-3 roles, phases, execution mode (`direct`, `isolated_planner`, `isolated_scout`), approval gates, and unloaded modules; (3) `state.StateMachine` provides an append-only lifecycle state machine that persists each run to `.figmaforge/runs/<run_id>/state.json`, enforcing forward-only phase transitions through `_is_valid_transition` and recording decisions, validations, approvals, blockers, and evidence; (4) The design-IR resolution side starts with `normalizer.Normalizer` converting raw Figma API responses into typed `FigmaFile`/`Node` objects without I/O; `resolver.Resolver` orchestrates `ComponentIndex` + `VariantResolver` + `ComponentMatcher` + `TokenResolver` to produce a schema-validated `ResolutionReport` categorizing matches as `resolved`/`ambiguous`/`missing` and emitting token references rather than duplicated values; (5) `token_resolver.TokenResolver` classifies variables/styles into seven semantic categories (color, typography, spacing, radius, shadow, opacity, breakpoint) and prefers existing library tokens by normalized name then value; (6) `variant_resolver.VariantResolver` parses variant properties from instance `componentProperties` and component-set child names; (7) `render_harness.RenderHarness` is a Playwright-based placeholder harness for deterministic screenshot/layout verification. Cross-cutting conventions include dataclass result types with `to_dict()` serialization, deterministic pure functions for matching/normalization, and explicit refusal to guess on ambiguous matches.
