Each file is an independent executable hook with its own `main()` entry point, designed to be spawned as a subprocess by the parent plugin. Communication follows a uniform contract: read JSON from stdin, print a JSON result to stdout, and exit with a status code (0 = safe/skipped/pass, non-zero = block/ask). `external_mutation_gate.py` inspects Bash commands and MCP tool names against regex patterns and allowlists to decide whether user permission should be asked before execution. `post_edit_validator.py` maps changed file extensions to language-specific validators (pyright, tsc, rustfmt, clang-format, gofmt, yamllint, jsonlint, sqlfluff) and runs them via `subprocess.run` with a 30s timeout, skipping when binaries are missing on PATH. `session_detector.py` imports the sibling `detector.RepositoryDetector`, runs repo classification, and injects concise language/framework/package-manager context only when confidence ≥ 0.3. Dependency direction is one-way: hooks depend on the plugin core (`detector`) but nothing in the core depends back on these hooks; they are pure side-effecting utilities called from outside.
