- Every public model class in `layout_types.py` is a dataclass exposing a `to_dict()` method that uses the shared `_round` helper and `_compact` to drop `None` values while preserving falsy-but-present fields like `0` and `False`.
- Ambiguous or unsolvable layout decisions are never guessed: unresolved sizes remain `None` and are surfaced as `Diagnostic` entries with codes like `underdetermined`, `bounds_mismatch`, or assumption-specific codes prefixed with `assumption:`.
- Cross-cutting constants for vocabulary values (display modes, sizing modes, anchor names, overflow behaviors, severities, confidence bands) are declared as module-level string/float constants in `layout_types.py` and imported by consumers rather than redefined inline.
- The engine separates concerns by delegating pure arithmetic to `BoxSolver` static methods (`size_from_fixed`, `size_from_fill`, `size_from_percent`, `size_from_hug`, `content_box`, `padding_offsets`, `delta`) so inference logic stays free of box math.
- Responsive behavior is detected purely by evidence: `BreakpointModel.infer` diffs deterministic node signatures across consecutive widths and emits a `BreakpointChange` only when a field actually differs, otherwise recording the node id under `no_change`.
- Confidence scoring is additive and penalty-based: start at 1.0, subtract per-assumption weights from `_ASSUMPTION_PENALTY`, subtract 0.10 for any `bounds_mismatch` diagnostic, then clamp to [0, 1].
