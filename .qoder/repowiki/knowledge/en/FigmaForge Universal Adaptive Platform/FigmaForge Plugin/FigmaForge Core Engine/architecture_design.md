The core module exposes four entry points via `__init__.py` — `RepositoryDetector`, `Router`, `Catalog`, and `StateMachine` — that together form the top-level orchestration layer. `Router` consumes a `Catalog` (loaded from `catalog/roles.json`) and a `RepositoryDetector` to score roles, select phases, determine execution mode, and compute approval gates; its output drives downstream pipelines. `StateMachine` enforces a fixed lifecycle (`intake → discover → define → design → plan → implement → verify → release → operate → learn`) with atomic JSON writes under `.figmaforge/runs/<run_id>/state.json`, append-only event logging, evidence tracking, approvals, and blockers, so every child pipeline must transition through it rather than mutating shared globals. The remaining files are cohesive sub-pipelines consumed by the router/state machine: asset handling (`asset_handler.py`, `asset_manager.py`, `asset_types.py`, `library_types.py`, `component_index.py`) resolves Figma references to local content-addressed storage; IR building (`ir_builder.py`, `normalizer.py`, `ir_types.py`, `ir_validator.py`, `generator_types.py`) normalizes Figma nodes into a framework-neutral IR validated against a JSON schema; layout analysis (`layout_analyzer.py`, `layout_engine.py`, `layout_types.py`, `breakpoint_model.py`, `constraint_model.py`) infers flex/grid/absolute plans; code generation (`react_generator.py`, `css_generator.py`, `render_harness.py`) emits VNode trees and CSS; and the repair loop (`diff_engine.py`, `repair_classifier.py`, `patch_planner.py`, `patch_executor.py`, `repair_loop.py`, `repair_history.py`) diffs rendered output against the plan and iteratively patches source until similarity thresholds are met. Cross-cutting concerns — typed Figma API models (`figma_client.py`, `figma_types.py`, `figma_errors.py`), token/component/variant resolution (`token_resolver.py`, `resolver.py`, `variant_resolver.py`, `matcher.py`), and plugin-side hooks (`hooks/external_mutation_gate.py`, `hooks/post_edit_validator.py`, `hooks/session_detector.py`) — are imported as needed by the higher-level orchestrators but never mutated directly by them.
