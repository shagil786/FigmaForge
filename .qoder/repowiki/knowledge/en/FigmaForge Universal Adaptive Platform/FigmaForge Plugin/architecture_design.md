The plugin is organized as a layered system: `agents/` and `skills/` provide declarative role definitions consumed by `core/router.py`, which dispatches incoming tasks to subagent handlers; `core/` implements the stateful pipeline (detection → resolution → IR building → layout inference → repair loop → code generation) and reads shared data from `catalog/roles.json`, `library/components.json`, `library/tokens.json`, and JSON-Schema files under `schemas/`. `hooks/hooks.json` registers session/tool lifecycle hooks used by both core and agents, while `templates/` supplies MCP/LSP server configs for external integration. The `tests/` suite drives the same pipeline against `fixtures/figma/*.json` and validates outputs via golden snapshots in `tests/snapshots/`, ensuring the core engine's contract with schemas and libraries remains stable across changes.
