Install prerequisites (Claude Code CLI, Python 3.8+), then validate and load the plugin via `claude plugin validate --strict plugin/figmaforge` and `claude --plugin-dir ./plugin/figmaforge`; run detector tests with `python3 plugin/figmaforge/tests/test_detector.py`; build and test the runtime separately from `runtime/`. End-to-end demo is invoked through the `/figmaforge:demo` skill once the plugin is loaded.
