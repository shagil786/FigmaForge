# Perceptual Diffing (SSIM) + Baseline Auto-Refresh (Part 13) — Design Spec

## Context

- Part 12 (merged, PR #13) delivered real raster diffing: `png_codec.py` (stdlib decode/encode), `figma_assets.py` (baseline download into the content-addressed `AssetManager`), a real `DiffEngine._diff_raster` with per-channel `color_threshold` (default 16), contiguous diff-region detection + node attribution, `noise_floor` (diffRatio ≤ 0.01 → `pixels` = 1.0), capped `pixel_weight=0.15`, deterministic capture (fixed viewport, `deviceScaleFactor=1`, `document.fonts.ready`, animations killed), `pixel_mismatch` classifier registration, and TS `screenshot_compare.ts` shell-out with a SHA-256 hash fast-path and `cmdCompare --baseline`.
- `DiffEngine.diff(plan, render_meta, render_screenshot=None, baseline_png=None, raster_options=None)` composes the score as `(1 - pixel_weight) * structural + pixel_weight * pixels_category`; `RasterOptions` (diff_engine.py) validates the knobs (`color_threshold`, `noise_floor`, `min_region_area`, `pixel_weight`) and `RepairConfig` (repair_loop.py:58) mirrors them with defaults and `to_dict()` coverage.
- Region contract (verified): `detect_regions` returns tight flood-fill bboxes `{"x", "y", "width", "height", "area"}` with `min_region_area=8` — regions can be as small as 8px (e.g. 2×4), and text antialiasing produces MANY such small regions.
- Two known limitations remain (both were Part 12 non-goals):
  1. **Pixel-count diffing is not perceptual.** A render that differs only by antialiasing/font-hinting jitter still produces diff regions and lowers `pixels` even when a human sees no change. Part 12's `color_threshold` and 1% noise floor blunt this but cannot distinguish "perceptual noise" from "real localized change" — a genuine 0.4% button-color change (the smoke-test case) and a 0.4% AA-jitter case score identically.
  2. **Baselines are static.** Part 12's design spec flagged "Figma exports not byte-stable over time → baseline refresh is manual and explicit" as a risk. Once a Figma design is edited (or the local font stack changes), every subsequent render diffs against a stale baseline and reports permanent false mismatches until a human re-downloads.
- SSIM (structural similarity) is the standard perceptual metric: a windowed comparison of luminance means/variances/covariances that yields ~1.0 for perceptually identical images and drops only on structurally meaningful change. A naive global-mean SSIM would MISS a small localized change (the button case stays ~0.99) — so the design must be **regional**: evaluate SSIM per detected diff-region bbox.
- Auto-refresh and SSIM are complementary: SSIM provides a trustworthy "visually identical" verdict, and auto-refresh may then safely adopt clean renders as the new baseline — SSIM guards B from absorbing real regressions.

## Decisions (user-approved)

- **Scope: A (SSIM) + B (baseline auto-refresh).** Diff heatmap (C), native TS pixel diffing, image resampling beyond the fixed SSIM downsample, and extended PNG formats remain non-goals.
- SSIM is computed in **pure-Python stdlib** (no numpy — the repo's stdlib-only convention), downsample-first for bounded cost.
- SSIM is a **gating signal alongside** the per-pixel diff, not a replacement: per-pixel diffing still drives region detection/attribution (repair targeting needs exact pixels); SSIM provides the perceptual verdict that decides whether those regions are real mismatches or noise.
- **SSIM is always computed** (when `ssim_enabled` and sizes match) but **gates only when diffRatio > `noise_floor`** — this keeps `raster_stats` uniform so SSIM doubles as a drift-tracking diagnostic (review fix F8).
- Auto-refresh is **opt-in** (`RepairConfig.refresh_baseline: bool = False` default) — Part 12's "manual and explicit" semantics remain the default; it adopts a render as the new baseline **only** when the SSIM verdict is clean, and it **never modifies the original Figma baseline file** (provenance — review fix F2).
- New knobs live in both `RasterOptions` and `RepairConfig` (validated in `__post_init__`, covered by `to_dict()`), same pattern as Part 12.

## Design

1. **SSIM module** — new `plugin/figmaforge/core/ssim.py`, stdlib only. Core primitive `ssim(a: PngImage, b: PngImage, window: int = 8) -> float` operating on the luminance plane (per-channel average), after downsampling both images by 2×2 averaging until the long side ≤ 256px (deterministic, integer averaging, no sampling jitter). Mean/variance/covariance computed with integral-image style sums so cost is O(N) per window size. Stabilization constants are pinned: `C1 = (0.01 * 255) ** 2`, `C2 = (0.03 * 255) ** 2` (dynamic range 255 — required for well-defined luminance-shift behavior; review fix F5). Identical inputs → exactly 1.0; modest uniform shifts → high; structured change → low. **Guard:** images smaller than `window` (or with a dimension < 2 after downsampling) raise `ValueError` — the caller treats a region it cannot measure as real, never as clean. Regional use is supported by a crop-scoped variant (or slicing the already-decoded buffers to the bbox) so integral-image cost is O(bbox), not O(image) per region (review fix F6).
2. **Regional gating in `_diff_raster`** — returns `(mismatches, raster_stats, diff_ratio, clean)` explicitly (review fix F3); `clean` is the verdict `diff()` uses for `pixel_score`, not a key sniffed out of the stats dict. Logic, after the existing per-pixel pass:
   - If `ssim_enabled` and sizes match: **always** compute global SSIM (downsampled scale) and record it in `raster_stats["ssim"]`.
   - diffRatio ≤ `noise_floor` → `clean = True`, no SSIM gating needed (SSIM value still recorded per the always-compute rule).
   - Else, for each detected diff region: **grow the bbox to exactly `window × window`** (clamped to image bounds; review fix F1) and compute SSIM over the grown bbox at full resolution. If clamping cannot fit the window (region at an image edge) → that region has **no verdict → treated as real**. `min_region_ssim = min` over regions with a verdict; regions without a verdict force `clean = False`.
   - `clean = True` iff `min_region_ssim ≥ ssim_threshold` (default 0.95) — or, when zero regions exist (scattered sub-`min_region_area` noise), if global SSIM ≥ threshold. A clean verdict suppresses pixel-mismatch emission and sets `pixels = 1.0` in `diff()`.
   - Otherwise emit the attributed `pixel_mismatch` regions exactly as Part 12 does, `pixels = 1 - diffRatio`.
   - `raster_stats` always carries `"ssim"` (float, when enabled+sizes match), `"min_region_ssim"` (float | None), and `"ssim_clean"` (bool) for report consumers; the explicit `clean` return drives `diff()`.
   - `RasterOptions`/`RepairConfig` gain `ssim_enabled: bool = True` and `ssim_threshold: float = 0.95` (validated to `[0, 1]`); `ssim_enabled=False` restores exact Part 12 behavior (no SSIM keys, no gating).
3. **Baseline auto-refresh** — `RepairConfig` gains `refresh_baseline: bool = False` and `max_baseline_refreshes_per_run: int = 3`. In `repair_loop.py`, after a diff whose verdict is **clean** (and sizes matched), and only if `refresh_baseline` is set and the per-run budget is not exhausted: write the render to a **versioned sibling file** `<stem>.refreshed.<n>.png` (n = refresh count), repoint `self._config.baseline_png` at the newest file, and record `"baseline_refreshed": true` (and the new path) in that iteration's result. **The original `baseline_png` file is never modified** — the Figma export keeps its provenance and full refresh history is retained (review fix F2). Repointing the config field flows into the next iteration's `diff()` automatically (it already reads `self._config.baseline_png`). Refreshes are bounded per run; adoption is **self-stabilizing** because capture is deterministic: once adopted, a subsequent clean render is byte-identical to the new baseline and the hash fast-path short-circuits, so no churn. Never refresh on size mismatch, on a non-clean verdict, or when `refresh_baseline=False`. **Fail-fast combo check** in `RepairConfig.__post_init__`: `refresh_baseline=True` requires `ssim_enabled=True` (review fix F4) — otherwise refresh would silently never fire.
4. **Python CLI + TS wiring** — `python3 -m core.pixel_diff` output JSON gains `"ssim": float | null`, `"min_region_ssim": float | null`, and `"ssim_clean": bool | null` plus a `--ssim-threshold` flag (default 0.95). `screenshot_compare.ts` parses the new keys into the existing `ScreenshotComparison` interface (optional fields; missing keys → null, so old output remains parseable); the hash fast-path is unchanged. `cmdCompare` prints the perceptual verdict when `ssim_clean` is present (e.g. "Perceptually identical (SSIM 0.982, N diff pixels)") so the CLI reports the *verdict*, not just numbers (review fix F7).
5. **Testing** — no binary fixtures; deterministic patterns generated at test time via `png_codec.encode_png`:
   - `ssim` unit tests: identical → exactly 1.0; a **modest** uniform luminance shift (e.g. +20, verified ≤ 0.95 at mid-gray) → high, plus a relative-ordering assertion (uniform shift scores far above a structural change of equal pixel count — review fix F5); a small localized change → **global SSIM stays high while regional SSIM over the changed bbox drops below threshold** (the keystone test proving regional gating catches the button-color case that global mean SSIM would miss); structured checkerboard noise → low; `ValueError` on size mismatch and on images smaller than the window; downsample bound on large inputs.
   - `_diff_raster` gating: AA-style noise (deterministic sub-threshold jitter pattern) → clean verdict, no mismatches, `pixels` = 1.0, `ssim` in `raster_stats`; real localized change → mismatches still emitted, `pixels = 1 - diffRatio`; **tiny-region case** (a 2×4 region whose grown bbox still can't fit the window) → treated as real, never suppressed; region at an image edge → same conservative fallback; sub-floor diff still records `ssim` (always-compute); `ssim_enabled=False` → exact Part 12 behavior (no SSIM keys); size mismatch → unchanged single-mismatch path, `clean=False`.
   - Auto-refresh: `repair_loop` with a fake `render_fn` producing byte-different-but-clean renders → a versioned `<stem>.refreshed.<n>.png` appears, `config.baseline_png` repoints at it, the original baseline file is byte-identical before and after, and the refresh event is recorded; refreshes bounded at `max_baseline_refreshes_per_run`; a real regression (low region SSIM) → never refreshed; `refresh_baseline=False` → never refreshed; `RepairConfig(refresh_baseline=True, ssim_enabled=False)` → `ValueError` at construction; size mismatch → never refreshed.
   - TS: pixel_diff parsing with and without the new keys (missing → null); `cmdCompare` output includes the SSIM verdict line; existing comparator suite stays green.
6. **Docs** — `docs/repair-loop.md`: new SSIM section (regional gating, always-computed diagnostics, knob table: `ssim_enabled`, `ssim_threshold`, `refresh_baseline`, `max_baseline_refreshes_per_run`) and an auto-refresh section (opt-in, clean-verdict-only, bounded, provenance-preserving sibling files, self-stabilizing). `docs/DEVELOPMENT_LOG.md`: Part 13 entry with final test counts. ## Noise-risk mitigations

1. **Regional SSIM gating** — AA/font jitter scores high SSIM per region → suppressed; a genuine localized change scores low SSIM in its own bbox → still reported. Global mean SSIM alone would miss small real changes; regional evaluation is the guard.
2. **Small regions are never suppressed by default** — a region whose grown bbox can't fit the window (or sits at an image edge) gets no verdict and is treated as real; the gate only suppresses changes it could actually measure.
3. **SSIM always diagnostic** — global + min-region SSIM land in `raster_stats` on every enabled raster diff, even sub-floor, so thresholds can be tuned from real data and gradual drift is visible (a clean step today that trends downward in `ssim` over runs is a warning).
4. **Opt-in auto-refresh, clean-verdict only, bounded, provenance-safe** — `refresh_baseline` defaults to False; adoption requires the SSIM clean verdict, consumes a per-run budget, writes versioned sibling files, and never touches the original Figma export — so a slow real regression SSIM misjudges can be absorbed at most `max_baseline_refreshes_per_run` times per run, is recorded per iteration, and the original baseline is always recoverable.
5. **Self-stabilizing adoption** — deterministic capture means an adopted baseline converges (next clean render hits the hash fast-path); no unbounded churn.
6. **Pure-stdlib, cost-bounded** — downsample-to-256 + integral-image window sums keep SSIM cheap; regional SSIM computes only inside grown bboxes (crop-scoped, O(bbox)).
7. **Fallback knobs** — `ssim_enabled=False` restores exact Part 12 behavior; `ssim_threshold` is tunable; the `refresh_baseline`+`ssim_enabled` combination is rejected at config time; `require_approval` remains available for conservative workflows.

## Documented tradeoffs (accepted, not "fixed")

- **Perceptual gating is stepwise-blind** — each individual diff can be "clean" while cumulative drift is real (e.g. a font rendering 2px smaller week over week). The backstops are the geometry/style checks (primary repair drivers), the IR as immutable source of truth, and the always-computed SSIM trend in `raster_stats`.
- **Diffuse sub-region noise** (diffRatio > 1% with zero ≥8px regions, e.g. dithered gradients) is judged by the downsampled global SSIM → clean. That is intended: such content is perceptually similar; the geometry/style checks still catch structural drift.
- **Global SSIM is downsampled-scale; regional SSIM is full-resolution** — two different signals by design. Do not "harmonize" them later; the global value is the coarse drift diagnostic, the regional value is the per-region verdict.

## Non-goals

- Diff heatmap image output (C — deferred; reuses the same region data, cheap to add later).
- Native pixel diffing in the TS runtime (shell-out only, per Part 12).
- Image resampling beyond the fixed 2×2 downsample used for SSIM.
- Grayscale/palette/16-bit PNG support.
- Scheduled/cron baseline refresh — auto-refresh is scoped to the repair loop, not a background job.
- Backend implementations (unchanged from Part 12).

## Risks

- **SSIM cost on very large images** → mitigated by the 256px downsample bound and integral-image windows; regional computation is confined to grown bboxes.
- **Regional gating masking a genuinely tiny change** → threshold defaults to 0.95 and is tunable; SSIM is always reported; any region below threshold — or any region too small to measure — still emits a mismatch.
- **Auto-refresh absorbing a misjudged regression** → bounded budget, clean-verdict-only adoption, versioned refresh files, per-iteration event recording, and the existing `require_approval`/`auto_rollback_on_regression` guards all remain in force.
- **Pure-python SSIM correctness** → deterministic fixtures (identical → 1.0, modest uniform shift → high, structured noise → low) plus pinned C1/C2 constants and the regional-vs-global test pin the exact behavior.
- **Baseline drift from real Figma edits** → unchanged from Part 12: auto-refresh only adopts *renders the loop itself produced*; re-downloading from Figma remains the explicit way to sync a design change, and the original baseline file is never overwritten.
